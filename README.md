## How to get into a game in BallMaster:

1. Launch the Game
2. Either Host a Game (you Will have to send the ID of the session) or Join a Game
3. Play around!

## How to play BallMaster:

| Action | Keyboard & Mouse | Gamepad |
| :--- | :--- | :--- |
| **Move** | <kbd>W</kbd> <kbd>A</kbd> <kbd>S</kbd> <kbd>D</kbd> | Left Stick |
| **Look / Aim** | 🖱️ Mouse | Right Stick |
| **Jump** | <kbd>Space</kbd> | South Button (A / X) |
| **Slide** | <kbd>C</kbd> or <kbd>Left Ctrl</kbd> | Right Stick Button (R3) |
| **Sprint** | <kbd>Left Shift</kbd> | Left Trigger (LT / L2) |
| **Launch Ball** | 🖱️ Left Click | Right Trigger (RT / R2) |
| **Drop Ball** | 🖱️ Right Click | East Button (B / O) |
| **Pause** | <kbd>Esc</kbd> | Start / Options |

### OTHER

* **Wall Run:** Automatic (run towards a wall).
* **Wall Jump:** Press **Jump** while wall running.

> To toggle **Fullscreen**, press <kbd>Alt</kbd> + <kbd>Enter</kbd>.
